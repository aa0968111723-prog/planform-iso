## Round 7（2026-08-28，PR #19 互動流程輪）— 匿名圖像盲測，E310 30 人實景

**方法**：`grok` CLI 1.0.5，單張匿名 PNG（本輪重產的 E310 30 人 iso 算圖），
放在一個空目錄裡，提示詞只說「看這張圖」並要求四件事：這是什麼地方、什麼活動
幾個人、走一次動線、有沒有看起來錯的地方。**沒有給 repo、文件、產品名稱或任何
預設答案**，並明確要求它不要猜產品或公司。

**它答對的**：大學教室、脫鞋席地的禪修／冥想社課、綠色拼接巧拼、走廊入場、
教室內報到、鞋子與背包分開、講台＋投影幕、14×5＝70 片的墊區，以及完整動線
（走廊 → 門 → 報到 → 鞋 → 包 → 墊區面向螢幕）。**0 P0。**

### 逐項處置

| # | Grok 說 | 判定 | 處置 |
|---|---|---|---|
| R7-1 | 「脫鞋的位置放錯了——鞋區在對面，照著標示走的人會穿著鞋走過整間教室」 | **成立，但成因不是版面** | 「鞋子｜右側」的標籤幾乎整片被「背包｜課桌椅」蓋住，圖上看起來只有一個鞋區。**計畫是對的，圖說了另一件事。** 已修：`src/scene/labelLayout.ts`（比標籤自己的大小，不比 zone 矩形），8 條測試 |
| R7-2 | 「70 人的說法和畫出來的置物空間不符」 | **不成立** | 它把 70 **片**讀成 70 **人**。標籤寫的是「70 片」，這是 30 人的場佈（每人約 2.3 片）。不改；但值得記著：一個沒有預設的讀者確實會從片數推人數 |
| R7-3 | 「唯一的門旁邊只有一張報到桌，是瓶頸；而且門是往內開，跟它搶同一塊空間」 | **工具已經在回答這件事** | 幾何阻擋有規則（`registration-blocks-entry`），這份場佈沒有觸發＝報到桌不在門前淨空區內。而「人多會塞」正是模擬要回答的：60 人情境自己會說「最塞：報到」。不改 |
| R7-4 | 「墊區是 5 寬 × 14 深的長條，最後一排離螢幕很遠」 | **不成立** | 反了：14 **寬** × 5 **深**（14 欄沿教室 12 公尺長邊）。8.4 × 3 公尺，不是長條 |
| R7-5 | 「兩個講者位置互相矛盾：講台上有講桌，前面又有一塊講師禪定區」 | **不是缺陷，但圖沒解釋** | 兩者都有現場證據：講者拿無線麥克風在講台與墊區之間走動（`REFERENCE_MAPPING`「講者動線」列），禪定區是他坐下的地方。不改 |
| R7-6 | 「生活組的箱子擋在入口動線上」 | **邊界情況** | 現場證據說生活組區在「教室側邊／後方，不預設佔用走廊」，目前確實在教室內靠門處。沒有觸發任何規則。不改，記錄 |

**這一輪最值得記的一件事**：R7-1 是**只有把圖打開來看才會發現的缺陷**，而且
單元測試永遠測不到它——場佈資料完全正確，錯的是兩個 sprite 疊在一起。一個
有能力的讀者因此把一份**正確**的計畫讀成錯的，還寫成了一條 P1。
被蓋住的標籤不只是難看。

## Round 4（2026-08-21，RC `9f2807b`）— **Claude-run pass，不是 Grok 實測**

### 誠實聲明（先讀這段）

本輪**沒有 Grok**。原因是環境，不是選擇：

| 想做的事 | 實測結果 |
|---|---|
| 安裝 Grok CLI（`irm https://x.ai/cli/install.ps1`） | `x.ai` 被 egress proxy 擋掉（CONNECT 403），**連下載都不行** |
| 盲測 `planform-iso-k7d2.zeabur.app` | 同樣 CONNECT 403，**production 完全不可達** |
| Codex CLI 實作 | npm registry 通、裝得起來，但需要互動式登入，**使用者未登入** |

所以本輪由 **Claude 兼任實作與對抗檢查**，方法是：用 Playwright 驅動
**`dist/` 的 `vite preview`（production build，與部署同一份產物）**，
以第一次使用者身分走完 E310 golden flow，在 phone / tablet / desktop 三種
viewport 各跑一次，並**實際打開匯出的 PNG 用眼睛看**。

這**不能取代** Grok 對 production URL 的盲測。Production Gate 仍未通過，見
`CURRENT_STATE.md` §0。

### 方法

- 產物：`dist/` → `vite preview :4173`（`?e2e` 開 debug hook）
- 路徑：清空 localStorage → 精靈第一屏 → 點「⚡ E310 演講範例（60 人）」
  → 檢查專案 → 版面量測 → 30/60/100 人模擬（`startSimulation` 後 `replaySimulation`）
  → 五種場刊圖各出手機版與 A4 → 夥伴模式 → 深色切換 → reload
- 三個 viewport：390×844 / 820×1180 / 1366×900
- 證據：截圖與 PNG 留在工作目錄（未 commit）
