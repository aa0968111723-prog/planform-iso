# PLANFORM 品牌系統

## 1. 品牌名稱

**PLANFORM**

中文產品描述：**活動空間彩排工具**

建議完整寫法：

> **PLANFORM｜活動空間彩排**

品牌標語：

> **先排好，再上場。**

PLANFORM 不再只被描述成「3D 等角場佈工具」。目前產品能力已涵蓋多專案、場地、場佈、3D 道具、文宣與印刷、互動流程、人流模擬、夥伴模式與場刊輸出，因此品牌必須能容納完整活動製作流程。

---

## 2. 品牌定位

PLANFORM 是給活動企劃、學生社團與現場工作人員使用的 **活動空間設計與彩排工具**。

使用者不需要懂 CAD、Blender、Unity 或模擬工程，也能：

1. 建立活動專案
2. 選場地或自訂場地
3. 排桌椅、地墊、攤位與 3D 道具
4. 設計動線與互動流程
5. 先看人怎麼走、哪裡會塞
6. 調整後再彩排
7. 匯出夥伴看得懂的場刊圖、工作圖與物資／送印資訊

核心承諾：

> **把活動在真正開始以前，先看懂、先排好、先走一次。**

---

## 3. 品牌核心價值

### 看得懂
第一層永遠使用活動工作者能理解的語言，不把工程名詞推給使用者。

### 像真的
場地、道具、地墊、隊伍、人物、文宣與空間關係要盡可能接近真實現場；沒有資料就誠實標示「待校正／估計」。

### 能彩排
不是只有畫圖。空間、人物、工作人員、服務站與互動流程必須能連在一起跑。

### 能交付
最後輸出必須能直接給夥伴、LINE 群組、活動工作人員或送印端使用，而不是只能截編輯器畫面。

---

## 4. 品牌語氣

應使用：

- 清楚
- 簡短
- 行動導向
- 現場用語
- 誠實描述估計與限制

避免：

- 過度工程化術語
- 假裝精確
- 「AI 已完成」但實際沒有改動畫面／資料
- 為了顯得專業而增加不必要設定

例：

- `Run DES Simulation` → `開始彩排`
- `Station utilization 97%` → `這一站快忙不過來了`
- `Asset Instance` → `場上的道具`
- `Interaction Anchor` → `參加者站位 / 工作人員站位 / 排隊起點`

---

## 5. 視覺方向

### 主視覺

PLANFORM 的正常預設是明亮、乾淨、可閱讀的「活動設計桌面」，不是深色工程監控台。

建議視覺語言：

- 暖白／淺灰背景
- 淡藍灰空間層次
- 清楚的高對比文字
- 少量品牌主色只用於主要操作、選取與狀態
- 3D 場景使用柔和陰影、接觸感與材質差異
- 場刊輸出維持紙面感與高可讀性

### 品牌主色原則

不要在此文件鎖死單一 HEX 作為所有場景的裝飾色。品牌 Accent 應集中用於：

- 主要 CTA
- 目前選取
- 重要進度
- AI 幫我
- 品牌識別

地墊、路線、區域、警告等功能性色彩依語意決定，不應全部染成品牌色。

## 6. 資訊架構品牌化

一般使用者第一層：

> **我的專案 → 場地 → 場佈 → 動線／互動 → 彩排 → 分享**

不要把 Props、DES、Catalog、Provider、Mesh、JSON、Simulation Seed 等名詞變成主導航。

道具工作室的第一層：

> **做什麼 → 長什麼樣 → 怎麼互動 → 放進場地**

## 8. Release Brand Gate

任何正式 Release 必須確認：

- Browser title / PWA name / App header 使用同一個 PLANFORM 品牌
- README 第一屏能說清楚「活動空間彩排」而不是只說 3D 場佈
- 手機、平板、桌面 UI 視覺一致
- Loading / Empty / Error / Offline / Update 狀態都有一致文字與視覺
- 場刊、夥伴圖、物資清單的頁首／頁尾命名一致
- 不得出現「功能已完成」但實際沒有改資料或畫面的假成功
- 不得把待校正資料包裝成真實精確值

---

> **PLANFORM 是讓你在活動開始前，把場地、道具、人流和互動先排好、先彩排，再把清楚的場刊圖交給夥伴的工具。**
