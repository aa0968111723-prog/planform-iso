### 攤位互動：從「想像的骰子遊戲」改成社團真的在做的事

`淡大擺攤區` 裡的兩份企劃寫的是**「心情 OK 蹦」**攤位，不是骰子：

```
歡迎入口 → Q1 科系真心話（4 選項）→ Q2 自由書寫 → Q3「怪獸」（4 選項）
        → Q4 轉念練習（自由書寫）→ 4×4 矩陣選出 OK 蹦金句
        → 選卡片背面 → 翻面 → 領 OK 蹦小卡（背面印期初演講時間／地點／QR）
```

另有「大型手持看板（做成手機低電量的樣子）＋ 圓點貼紙投票」的招攬點子。

這對通用互動模型是很強的驗證：它需要的正好是
**多題、每題多選項、選項組合決定結果、中間有自由書寫、最後領實體小物**——
不是骰子專屬邏輯。若核心寫死成 DiceEngine／QuizEngine，這個真實活動就排不出來。
