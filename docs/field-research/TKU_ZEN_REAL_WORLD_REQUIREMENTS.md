# 淡江禪學社真實使用需求

這份文件的目的不是介紹社團，而是回答四個會直接決定 UI 的問題：

1. Planform 首頁該放什麼？
2. 最常用的物資是什麼？
3. 最常用的區域是什麼？
4. 夥伴真正需要看什麼？

依據：`docs/field-research/LOCAL_REFERENCE_AUDIT.md` 列出的本機真實資料
（E310 現場照、88 張活動實況照、社團知識庫）。

---

## 一、這個社團的活動長什麼樣子

從活動實況照可以直接看到的，不是推測的：

- **場地是一般教室，不是禪堂。** 桌椅被推到後面或側邊，中間地板鋪成活動空間。
- **綠色巧拼是主角。** 整片鋪滿教室中段，不是一張張個人坐墊。人直接盤腿坐在上面。
- **人的坐法是自由的，不是方格。** 沒有固定座位線，一個人大約佔 0.8–1 公尺見方，
  彼此不貼死。**這是排地墊功能必須貼合的事實**：使用者要的不是「幾張墊子」，
  是「這片墊子坐得下幾個人」。
- **中間留走道。** 多數場次可以看到中央有一條沒有人坐的通道，講者與工作人員從那裡走動。
- **前方有講者位置。** 有時站著（投影幕前），有時坐在地上與大家同高。
- **明心輪圓盤**（紅／黃／綠同心圓）幾乎每場都掛在前方牆面或立在講桌旁，
  是這個社團的標誌物 —— 對「一眼認出這是禪學社的場」有實質作用。
- **投影幕在前方中央**，兩側是黑板；投影機吊在天花板。
- **鞋子與個人物品放在巧拼邊緣**，不是鞋櫃。
- **後方長桌**放背包、水壺、報到用品。

## 二、一場活動實際的流程

走廊 → 引導 → 排隊 → 報到 →（已繳／未繳分流）→ 收費 → 脫鞋 → 放背包 → 進教室 → 巧拼入座

兩個關鍵事實影響設計：

1. **報到與收費常常在走廊做，不在教室裡。** 教室要留給座位；把服務桌塞進教室會壓縮
   坐得下的人數，也擋住門。
2. **人是陸續來的，不是一起到。** 開始前 15–20 分鐘陸續進場，前段人少、中段最擠。
   模擬如果一開始就把所有人放出來，看到的塞車位置會是錯的。

## 三、所以首頁該放什麼

**不是**「新增專案 / 匯入 / 設定」這種工具列思維，而是直接問：**今天要排什麼？**

- 【淡江 E310 + 走廊】—— 最常用的場地，一鍵進場
- 【淡江一般教室】—— 其他教室的起點
- 【我之前的場地】—— 存過的自訂場地
- 【空白場地】

接著只問這場活動需要什麼（地墊 / 報到 / 收費 / 鞋子 / 背包 / 講師 / 小組 / 工作人員動線）
與人數，然後直接給一個**可以改**的起點。

## 四、最常用的物資（第一層素材庫只放這些）

依實況照出現頻率，不是依「一般辦公家具」分類：

| 物資 | 為什麼在第一層 | 真實樣子 |
|---|---|---|
| 地墊（巧拼） | 每場都有，而且是主角 | **綠色** 60×60 拼接墊，整片鋪 |
| 桌子 | 後方長桌放背包／物資 | 一般教室長桌 |
| 椅子 | 推到旁邊或給工作人員 | 一般教室椅 |
| 報到桌 | 每場都有 | 長桌 + 名單 + 筆 |
| 收費桌 | 需收費的場次 | 長桌 + 收費箱 |
| 電腦 | 報到用 | 筆電放報到桌上 |
| 門 | 動線起點 | — |
| 投影幕 | 決定大家面向哪 | 前方中央 |
| 鞋子區 | 每場都有（要脫鞋） | 巧拼邊緣 |
| 背包區 | 每場都有 | 後方長桌上 |
| 生活組區 | 茶水／物資 | 走廊或教室後方 |
| 講師區 | 前方 | 投影幕前 |
| 小組區 | 分組活動場次 | 巧拼上分區 |
| 明心輪 | 社團標誌物，幾乎每場 | 紅黃綠同心圓立牌／掛牌 |

## 五、夥伴真正需要看什麼

夥伴（志工）拿到的是一張傳到 LINE 的圖，不是打開 App 操作。他要在三秒內知道：

1. **我在哪裡**（我這組的位置）
2. **人從哪裡來**（入口與方向）
3. **下一站送去哪**（動線的下一個點）
4. **我負責的東西在哪**（報到桌／收費箱／鞋子區／茶水）

所以場刊圖上必須清楚的是：入口、區域名稱、動線編號、以及自己那組的位置——
而不是尺寸標註、座標、或工程資訊。

## 六、這份研究否定了什麼

寫下來，因為這些是「照想像做」會做錯的地方：

- ❌ 把地墊當成「一張一張的個人坐墊」來排 → 實際是整片鋪，使用者關心的是坐得下幾人
- ❌ 地墊用紫色 → 實際是綠色（已修）
- ❌ 把報到／收費桌預設放在教室裡 → 實際常在走廊，放教室裡會擋門也吃掉座位
- ❌ 模擬時所有人同時出現 → 實際是 15–20 分鐘陸續到，尖峰在中段
- ❌ 首頁給工具列 → 應該直接問「今天要排什麼」
