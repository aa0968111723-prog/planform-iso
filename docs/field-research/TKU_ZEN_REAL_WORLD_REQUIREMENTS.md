## 2. 高頻活動類型與場佈差異（產品必須都能表達）

| 活動 | 頻率 | 場佈重點 | Planform 對應 |
|---|---|---|---|
| **每週社課** | 學期間每週一次，晚間 | 巧拼座區＋報到＋家族凝聚分享 | 主場景（golden scenario 的日常版） |
| **期初茶會** | 學期初 | 體驗禪＋**手作**（浮游花瓶）→ 需要**桌面** | 需要桌子而非純地墊；目前可手動加 |
| **期初／期中演講** | 每學期 1–2 次 | 人最多、有外賓講師、要收費、要報到分流 | **E310 Golden Scenario 就是這一型** |
| **期末社大** | 期末 | 溫馨聚會、送舊 | 同社課，重佈置感 |
| 禪訓營／挑戰營 | 寒暑假 | 校外 | 不在 1.0 範圍 |

> **產品裁決**：E310 Golden Scenario 對齊「**期初／期中演講**」——這是人數最多、
> 報到收費分流最複雜、最需要事前排圖的一型，也正是使用者指定的 60 人情境。

## 3. 真實社課流程（知識庫 §8.1 / §10.3）

```
17:30 工作人員集合
  → 用餐 ＋ 場佈          ← Planform 的產出就是給這一步用的
  → 禪定凝聚（工作人員）
  → 社員報到              ← 報到桌／生活組／名牌
  → 主持人開場、介紹師資
  → 師資上課（約 75 分鐘）  ← 巧拼座區面向投影幕
  → 社團／活動介紹
  → 凝聚分享（各家族座談）  ← ⚠ 座位形態會改變（見 R-06）
  → 場復
21:30–21:40 結束
```

**兩個對產品的關鍵推論**：

1. **Planform 的使用者是「場務組」**（場地布置、音控、燈控、拍照、控 PPT、借場地），
   使用時機是「場佈」那一格，也就是**活動當天現場、拿著手機或平板**。
   → 手機／平板必須好用不是加分項，是主要情境。
2. **一場活動有兩種座位形態**：上課時面向投影幕的整片座區，
   課後拆成各家族的小組座談。目前產品只表達第一種。

## 4. 組織分工 → 場佈區域對照（知識庫 §10.1）

| 組別 | 真實職掌 | 場佈上的位置 | Planform 現況 |
|---|---|---|---|
| **生活組** | **報到點名**、餐點、接待、聯絡學員 | 報到桌後方／走廊外側 | ✅ 有 life zone；⚠ 但「報到」與「生活組」在圖上是兩塊，現場其實是同一批人 |
| **場務組** | 場地布置、音控、燈控、拍照、控 PPT | 講台側、器材處 | ⚠ 無專屬區域（音控／PPT 位置未表達） |
| 活動組 | 主持、流程、破冰 | 講台前 | 併入講師區 |
| 美宣組 | 海報、文宣、**名牌製作** | 報到桌上 | ⚠ 名牌未進物資清單 |
| 招生組 | 接引新人 | 走廊引導 | ✅ guide station |
| **組輔／家族長** | 帶家族、課前課後凝聚 | 各家族座位 | ⚠ 見 R-06 |

## 5. 收費是真的（知識庫 §14 FAQ）

> 「以**社費**支應社課與活動（茶點、講師等）；營隊另有報名費。」

→ 「40 已繳／20 現場繳費」的分流**符合真實**：學期初尚未繳社費者當場繳。
→ 收費點應**貼著報到**（同一動線、不同桌），已繳者直接放行。產品現況正確。

## 7. 場刊圖／夥伴模式最需要一眼看到什麼

依社團實際運作（工作人員 17:30 集合、當天才看圖、多半用手機在 LINE 裡看）：

1. **我是誰、我站哪** — 夥伴模式第一屏就要回答
2. **E310 與走廊的關係** — 人從走廊來，門在哪
3. **①②③ 順序** — 引導→報到→收費→鞋子→背包→入座
4. **巧拼座區的位置與朝向** — 面向投影幕
5. **物資清單** — 場務組照著搬東西
6. **哪裡會塞** — 報到桌前

> 這六項就是 `docs/release-1.0/` 六張圖的存在理由，也是驗收標準。

## 8. 明確標示為「不知道」的事

不得靠想像補：

- E310 任何實測尺寸（長寬、門寬、地磚、講台）
- 社團是否真的有：鞋架、排隊欄杆、指示立牌、收費箱、報到用電腦
- 巧拼實際片數與備品量
- 本學期社費金額、社課時間地點（知識庫 §15 明列為每年更新欄位，未填）
- 家族數量與每家族人數

以上在產品內一律維持「待校正／待確認」或做成**可自由增刪的一般物件**，
不做成不可移除的固定設施。
