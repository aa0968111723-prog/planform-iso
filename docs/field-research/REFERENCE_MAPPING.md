# Reference / Evidence Mapping

每一個 preset 的長相都要說得出「憑什麼長這樣」。這份表把 Planform 的每個預設值對到
它的證據來源與可信度，避免 preset 變成黑盒。

可信度定義：

| 等級 | 意思 |
|---|---|
| `verified` | 現場照片或社團文件明確顯示，多個獨立來源一致 |
| `high` | 清楚可見，但只有單一角度／單一來源 |
| `medium` | 部分可見，需要推斷 |
| `estimated` | 由比例推算（必須寫出用什麼當比例尺） |
| `unknown` | 沒有資料，**不得**當成已知 |

證據來源代號：
- `[E310]` = `D:\場務場刊E310`（E310 空教室與走廊現場照，11 張）
- `[ACT]` = `D:\淡大所有照片`（禪學社活動實況照，88 張，2025-10-16 LINE 相簿）
- `[DOC]` = `D:\淡大禪學社AI\knowledge`（社團知識庫，108–115 學年度約 500 份文件）

## 七、社團自製的場佈圖（Planform 的 ground truth）

社團**已經在做這件事**，用兩種方式：

**(A) 投影版**（照片 `_2`）— 用試算表畫的：
- 細方格為單位（Excel/Sheets 儲存格）
- 黃色填色大矩形 = 地墊區
- **彩色圓點 = 每一個人**（4–5 色，代表角色或性別）
- 五個黃色標籤「第一家～第五家」呈**梅花形**擺放
- 左緣直書紅字 = 講師／活動區
- 左上角講台＋人的 icon
- 右側四欄小格 = 停放的課桌椅（其中一欄兩兩並排、每格有字）

**(B) 白板手繪版**（多張照片）— 只有四個元素：
- 上方圓角框：「桌子」／「講師」
- 中間大矩形：**「地墊」**
- 左緣一條窄框
- 下緣兩個小框

**這對 Planform 的意義**：
1. 預設畫布方向應該是**講台／投影幕在上**（兩種版本都這樣畫）
2. 最小可用圖只需要 4 個物件 —— 值得做一個「快速草圖」preset
3. 用**彩色圓點代表人**是這個社團既有的視覺語言，模擬人物應該沿用而不是發明新的
4. 右側課桌椅欄是他們真的會畫的東西，Planform 應該支援
