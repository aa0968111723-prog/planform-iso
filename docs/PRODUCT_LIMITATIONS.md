# 產品功能限制（1.0）

這份清單對齊產品裡「更多 → 已知限制」，也對齊
`src/core/productLimitations.ts`。

分類：

| 標記 | 意思 |
|---|---|
| **1.1 待辦** | 文件自己標成 1.1／limitation，規格或研究有、產品沒做完 |
| **只有欄位** | 儲存層或卡片有欄位，沒有完整產品入口（或只有顯示、沒有產生） |
| **現況限制** | 畫面上有入口，底層是 mock／離線規則／已知行為 |

活動日期（`eventDate`）曾經是「只有欄位」：repository 有 `setEventDate`，
卡片會顯示，但沒有編輯入口。1.0 現在可在專案卡片「活動日期」或
分享 → 活動資訊 裡填。

---

## 只有欄位

### 專案縮圖不會自動產圖

卡片會顯示 `thumbnail`（有圖就畫），空的用 ▦ 佔位。
`setThumbnail` 與 `renderConstructionPlan` 的縮圖路徑都在，
但儲存專案時**不會**自動產圖。產圖成本與時機（何時產、產幾次）
仍屬 1.1。

---

## 1.1 待辦

### 「這個專案的版本」仍是全域 named layout

編輯器標題寫「這個專案的版本（方案 A／方案 B／最後版）」。
儲存層仍是 `planform-iso:layouts`，以名稱為 key，跨專案共用。
真正的 project-scoped snapshot 還沒做。同名會蓋掉其他專案存的版本。

### 家族／小組座談座位（R-06）

社課流程後半段「凝聚分享」要拆成各家族圈。
目前只有上課時面向投影幕的整片座區。見
`docs/field-research/TKU_ZEN_REAL_WORLD_REQUIREMENTS.md` R-06。

### 場務音控／控 PPT 位置（R-07）

場務組在講台側的音控、燈控、控 PPT 位置沒有專屬區域。R-07。

### 名牌進物資（R-08）

美宣組做的名牌不會自動出現在報到桌物資清單。使用者可自行加物件。R-08。

### V2 報到流程精靈

`docs/MAJOR_OPTIMIZATION_V2_PLAN.md` §4 有 A–E 模板與一鍵分流
（同桌／分桌／入口先分流／多桌平行）。
產品沒有這層精靈；「動線 → 模擬活動」只問人數、現場繳費、人力、到齊時間。

## 現況限制

### 「掃描場地」偵測是假資料

場地 → 進階設定 → 掃描場地：上傳／拍照 → 檢視 → 校正 → 確認寫入，
這條流程在。偵測來自 `MockVenueProvider`，依檔名給固定候選，
**不會**認照片裡的門桌。

### 「✦ AI 幫我」不是雲端模型

離線規則／關鍵字（`MockProvider`）。沒金鑰也能用。
一律先預覽再套用。不是真 LLM。

### 兩個分頁開同一份專案

後寫入者勝。沒有合併、也沒有「他人正在編輯」提示。
不同專案各有一把 storage key，互不覆蓋；同一份才會互蓋。

### 線上 production 尚未實測過關

文件寫雲端容器連不到 Zeabur（egress 403）。
PWA 真機安裝／離線還沒在 production 過關。
本機 `prodSmoke`（preview）與 CI localhost 可以跑；那不代表線上過關。
